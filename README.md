# NLI: Neural Learned Index

An **indices system that fetches data in O(1) time** rather than the traditional O(n) fetch times of B+ tree-based index systems, utilizing a neural-net model implemented in C++.

This project demonstrates learned index structures that use machine learning models (such as linear regression or neural networks) to replace or augment classic database indexing data structures (like B+ Trees, PGM, ALEX). The approach is inspired by [The Case for Learned Index Structures (Kraska et al., 2018)](https://arxiv.org/abs/1712.01208).

> **Language composition:**  
> - Jupyter Notebook (65%)  
> - C++ (26%)  
> - Python (8%)  
> - CMake (0.2%)

## Features

- **Fast lookup:** Achieves sub-linear (approaching O(1)) query time for indexed keys.
- **Learned index models:** Replaces nodes of classic tree indices with machine-learned models.
- **Multiple baseline and advanced indexes:** Includes B+ Tree, ALEX, RMI, and other learned index implementations.
- **Extensive benchmarking:** Compares real-world data and classical baselines.
- **Python and Jupyter integration:** Includes data analysis and plotting scripts.

## Overview

_NLI_ leverages learned models—such as piecewise linear models, recursive model indexes (RMI), and neural networks—to predict the position of a key in a sorted array, dramatically accelerating search compared to the classical B+ Tree and interpolation search. It offers a modular structure for benchmarking and extending learned index approaches.

> **Typical Indexes Implemented:**
> - B-Tree (std::map baseline)
> - ALEX (Piecewise Linear Model)
> - PGM-Index
> - Simple/Enhanced Linear Models
> - Recursive Model Index (RMI)
> - Interpolation Search

## Build & Installation

This project uses standard CMake. The main C++ libraries and executables are in `src/`.

```bash
# From your NLI root directory:
mkdir build
cd build
cmake ..
make -j4
```

- **Optional:** Build documentation if [Doxygen](https://www.doxygen.nl/) is present.
- **Testing:** If [GTest](https://github.com/google/googletest) is installed, tests are available via `make test`.

## Usage

The main executables benchmark and verify different index structures.

```bash

```

